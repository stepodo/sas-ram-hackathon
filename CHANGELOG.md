## [1.0.0] - 2026-10-26

### Added

- Initial public release of the SAS Retrieval Agent Manager Hackathon resources.
- CineAgent reference implementation for movie analysis and story ideation.
- Document sources for movie summaries and movie success guidelines.
- RAG Collection configuration workflow with configurable chunk size and chunk overlap.
- Custom retrieval settings for movie summaries and movie success guidelines.
- Reusable User Eval Tests for Collection and agent evaluation.
- Movie Database MCP Server template with 25 tools for search, filtering, aggregation, statistical analysis, and visualization.
- CineAgent visual-output agent template for rendering generated charts.
- Three reference agent experiments:
  - Collections-only RAG baseline.
  - Collections plus MCP tools.
  - Template-based experiment with visual output.
- Supporting SAS programs and documentation.
